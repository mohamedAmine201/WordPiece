WordPiece Tokenizer From Scratch
===============================

Description
-----------
A simple Python implementation of the WordPiece tokenization algorithm using a Jupyter Notebook. The project explores vocabulary building, subword merging, text preprocessing, and tokenization.

Requirements
-----------
- Python 3
- Jupyter Notebook or VS Code with the Jupyter extension

Usage
-----
1. Clone the repository.
2. Open the .ipynb notebook in Jupyter or VS Code.
3. Select a Python kernel.
4. Run the cells sequentially to train the vocabulary and test the tokenizer.

Topics Covered
-------------
- Text preprocessing using regular expressions
- Initial character-level tokenization
- Subword frequency counting
- WordPiece scoring and merging
- Vocabulary construction
- Greedy longest-match-first tokenization

Note
----
This is an educational implementation intended to help understand how WordPiece works. It is not a production-ready tokenizer.
